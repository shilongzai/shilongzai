# 石龙仔文库 · Shilongzai Library

> 一个在银行干了十来年的金融人写的独立文库——写城市，也写时代与日常；不追热点结论，先把账算清楚。
>
> An independent Chinese essay library by a banker-turned-writer. Long-form, no ads, kept for the long run.

**官网 / Website**：https://shilongzai.com

## 这是什么

作者随笔石龙仔，在银行干了十来年，常驻东莞，写随笔写了很久。文章原先散在各个平台，今年起统一归档到自己的独立站，给文字一个长期的去处。本账号是文库的官方运营账号，由文库运营维护；作者本人只写文章，不在此发言。

## 站里有什么

- 正刊与「未刊集」两部分，共 23 篇长文，持续更新。有些文章，只在这里能看到完整版。
- 每篇文章都能听：作者本人原声读全文，他的朋友莫问友情献声，两个版本任选。
- 新文章先在本站上线，其他平台会晚一步。
- 留言不用注册，还能叠楼，想到什么直接说。
- 本站无广告，文字长久留存。
